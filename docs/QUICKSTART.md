# 五分钟上手

目标：手机装好 App，电脑开着 DSH，扫一次码就能连上。
信息雷达只在「自有服务器」形态出现；用官方中继时整套雷达界面不会出现。

## 0. 你需要

- 一台 arm64 的 Android 8.0+ 手机（建议 6 GB 内存以上）；
- 一台能跑 DSH 的电脑（Windows / macOS / Linux 均可）；
- 两者都能上网。中继默认用 `ds-harness-remote` 自带服务，不需要自己搭。
- 想让电脑在关掉 DSH 后仍在线：见第 5 节「让电脑常驻」。

## 1. 装 App

从 [Releases](https://github.com/ccch1mneyyy/dsh-buddy/releases/latest) 下载 `app-arm64-release.apk`：

```bash
adb install -r app-arm64-release.apk
```

或者在手机文件管理器里点开 APK 安装（需要允许「安装未知来源应用」）。
首次启动会解压内嵌运行时，大约 200 MB，等进度条走完。

> 自己构建：先跑 `runtime/build-runtime.sh arm64-v8a` 生成运行时资产，再 `flutter build apk`。
> 详见 [README](../README.md#从源码构建)。

## 2. 配电脑

1. 在电脑上安装 DSH，并装好 **`ds-harness-remote` Host 插件**（上游项目：
   [liguobao/ds-harness-remote](https://github.com/liguobao/ds-harness-remote)）。
2. 启动 DSH，确认 Remote 插件已启用（`~/.dsh/profiles/.../cordis.patch.yml` 里
   `ds-harness-remote` 为 `enabled: true`，并带 `role: host`）。
3. 打开 **Plugins → DS Harness Remote → Remote settings → Sign in → `DSH Go pairing`**，
   点 **Generate pairing QR code**。

> **二维码只在「这台电脑还没登录 Remote」时出现。** 已经登录的主机没有「添加设备」入口：
> 要么在手机端用同一个账号登录（不用扫码），要么先在 Remote settings 里 **Sign out** 再配对
> ——登出会断开这台电脑现有的远程连接。
>
> 如果桌面 App 里找不到 Remote 面板，说明当前 profile 把插件关掉了。可以改用无头 Web 界面：
> `dsh web --profile web --no-open` 会在日志里打印 `http://127.0.0.1:<port>/?token=…`，
> 用浏览器打开它，路径与上面相同。

## 3. 扫码配对

1. 手机打开「我的 → 主机 → 远程主机」。
2. 点「扫码配对电脑」，允许相机权限。没有相机权限时可用「从相册识别」或「粘贴配对链接」。
3. 对准电脑上的二维码。App 会先显示**这台电脑的名字、中继地址和主机指纹**——
   指纹要和电脑端显示的一致，再点「确认是这台电脑，开始配对」。
4. 手机显示一个 **8 位验证码**（倒计时约 1–2 分钟），把它输入电脑端的 Remote 面板，点确认绑定。
5. 电脑确认后，手机会自动连上，主机出现在列表里。

两个硬约束：

- **验证码只有一次机会**：输错或超时，这次配对作废，必须回电脑重新生成二维码再扫。
- **电脑端面板要保持打开**：关掉页面就没法输入验证码；二维码被手机扫过但未确认时，
  再扫同一张会提示「已过期或已经用过」，同样要重新生成。

## 4. 验证连接

- 「远程主机」列表里出现这台电脑，状态为在线；
- 点进去能看到它的会话列表，新建一个会话发一句话，能流式返回就说明通了；
- 回到「工作」页，顶部的主机名与连接状态应同步显示。

## 5. 让电脑常驻（可选）

远程插件跑在 DSH 进程里，关掉桌面窗口就下线。要让手机随时连得上：

1. 「远程主机」页 →「让电脑常驻」；
2. 点「复制命令」，整段粘到电脑的命令行里回车（无需管理员权限，约 1 分钟）；
3. 回到页面点「检测常驻主机」，出现同一台电脑的新条目后点「切换到该主机」。

命令会在 `~/.dsh/profiles/web` 里装一份插件并提供登录自启的后台进程；原来的桌面端
条目在关闭 DSH 后消失。

## 6.（可选）自建服务器与信息雷达

只有连到自己的服务器时，雷达页签才会出现：

1. 在 Ubuntu 22.04+/24.04 服务器上，以 root 执行：

   ```bash
   sudo tool/server/install-all.sh \
     --relay-host dsh.example.com \
     --radar-host radar.example.com \
     --email you@example.com
   ```

2. 记下 `/etc/dsh-buddy/access.txt` 里的地址、邮箱/密码、令牌；
3. 手机「我的 → 连接 → 自建服务器」填中继地址与邮箱密码登录；
4. 底部出现「信息雷达」，用同一台服务器的地址和令牌连接。

详见 [SELF_HOST.md](SELF_HOST.md)。切回官方中继后，雷达页签、自动化入口和后台轮询
会一起消失，服务器上的数据不受影响。

## 排错

| 现象 | 原因与处理 |
|---|---|
| 「远程主机」里没有「扫码配对电脑」 | 先返回再进一次：能力探测失败时入口会重试。仍然没有，说明当前中继不支持配对（缺少 `dsh-pairing-v1`）。官方 `dsh.r2049.cn` 支持；旧版自建 server 可能只支持密码登录，需要升级 |
| 电脑上找不到二维码 | 二维码只在主机**未登录**时的 `DSH Go pairing` 标签里。已登录请先 Sign out，或直接用同一账号登录手机；桌面 App 没入口时改用 `dsh web` 的本地地址 |
| 扫码后提示「连不上 Remote 服务器」 | 解析配对码时的瞬时网络失败，重试同一张码即可；连续失败检查手机到中继的 HTTPS（`curl https://dsh.r2049.cn/health`） |
| 扫码后提示「二维码已过期或已经用过」 | 这张码已被认领但没在电脑端确认。回电脑点 Cancel pairing / 重新生成，手机重新扫 |
| 扫码后提示 `PAIRING_SERVER_MISMATCH` | 二维码属于另一个中继。按提示切换，或把电脑端中继改成同一个地址 |
| 一直停在「读取二维码」 | 二维码过期（通常 3 分钟）。回电脑刷新二维码再扫 |
| 输入 8 位码后电脑没反应 | 检查电脑端 Remote 面板是否还在等待；验证码只有一次机会，输错需重新扫码 |
| 指纹不一致 | 可能连到了另一台机器或被中间人替换。停止配对，核对电脑端指纹后重来 |
| 手机端 App 一直「正在解压运行时」 | 存储空间不足或运行时资产缺失；换一台机器重新构建见 README |
| 雷达页连不上 | 地址必须是 `https://域名`（证书签给域名，不能填 IP）；令牌至少 32 字符 |
